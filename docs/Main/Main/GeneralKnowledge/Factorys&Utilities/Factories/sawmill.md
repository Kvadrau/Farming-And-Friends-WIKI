# Sawmill

The Sawmill is a production building that converts **logs into planks**. Planks can then be sold at forestry selling locations or the central one-stop sell point.

The Sawmill is part of the Forestry and Logistics progression and requires the **Sawmill License** to use.

## Factory Information

| Information      | Details                          |
| ---------------- | -------------------------------- |
| Purchase Price   | Not currently confirmed          |
| Main Input       | Logs                             |
| Product          | Planks                           |
| Required License | Sawmill License                  |
| Build Menu       | Create > Buildings               |
| Selling Location | WoodNStuff / One-Stop Sell Point |

The Sawmill converts forestry logs into higher-value planks.

## Required Materials

The Sawmill uses **logs** as its input.

| Material     | Details                                   |
| ------------ | ----------------------------------------- |
| Pine Logs    | Cannot currently be processed into planks |
| Cocoa Logs   | Can be processed into planks              |
| Cypress Logs | Can be processed into planks              |
| Birch Logs   | Can be processed into planks              |

According to the available tree documentation, **Cypress and Birch logs** can be turned into planks, while the newer 2026 guide also states that Cocoa harvests can produce logs that can be processed.

> **Note:** The exact log-to-plank conversion amount can vary depending on the log type.

## Production Time

A fixed processing time for the Sawmill is not currently documented reliably.

The Sawmill is operated as a processing building: logs are loaded into the input area and planks are collected from the output area.

> **Note:** The exact processing time should be confirmed in-game before adding a fixed value to the wiki.

## Products Produced

The Sawmill produces **Planks**.

| Product          | Details                          |
| ---------------- | -------------------------------- |
| Planks           | Produced from forestry logs      |
| Selling Location | WoodNStuff / One-Stop Sell Point |

Planks generally provide a higher-value alternative to selling the corresponding raw logs. For example, current community data lists Birch Planks at approximately **14,000 Coins per plank** at the rainbow value, compared with 10,080 for a Birch Log.

## Selling Price

Plank prices depend on the type of wood used.

| Wood Type | Approx. Plank Value |
| --------- | ------------------- |
| Cypress   | 9,750 Coins*        |
| Birch     | 14,000 Coins*       |

*These are the documented **Rainbow values**, not necessarily the normal selling price.

> **Note:** Selling prices can change with game updates. Always use the in-game sell value as the final source when recording current prices.

## Required Equipment

To operate the Sawmill efficiently, you will need:

* **Sawmill**
* **Sawmill License**
* **Forestry License**
* **Forestry equipment**
* **Tree seeds**
* **Forest Soil**
* **Log Trailer**
* **Suitable vehicle for transporting logs**
* **Suitable vehicle/trailer for transporting planks**

The equipment required depends on the type and scale of forestry operation. Pine trees can be harvested using a Chainsaw, while larger trees such as Cypress and Birch require heavier forestry equipment.

## How to Use the Sawmill

### 1. Unlock the Sawmill License

The Sawmill License is unlocked through the **Goals progression**.

The current 2026 progression guide places the Sawmill branch around **14,400 XP**, with linked tasks involving Cocoa harvesting, Chocolate Milk production and forestry/log processing.

### 2. Grow Trees

Plant suitable trees on **Forest Soil**.

Cypress and Birch are particularly useful for the Sawmill because their logs can be processed into planks.

### 3. Harvest the Trees

Once the trees are fully grown, use the appropriate forestry equipment to cut them down and collect the logs.

For example:

* **Pine** — Chainsaw
* **Cypress** — Tree Cutter
* **Birch** — Tree Cutter

The required equipment depends on the tree type and your Forestry licenses.

### 4. Transport the Logs

Load your logs into an appropriate **Log Trailer** and transport them to your Sawmill.

Wood trailers are recommended for moving larger quantities of logs.

### 5. Load the Sawmill

Place the logs into the Sawmill's input area.

Follow the on-screen prompts to deposit the logs into the factory.

### 6. Start Production

Start the Sawmill's production process.

The logs are processed into **Planks**.

### 7. Collect the Planks

Once processing is complete, collect the finished Planks from the Sawmill's output area.

### 8. Sell the Planks

Transport the finished Planks to:

* **WoodNStuff**
* **One-Stop Sell Point**

Planks can be sold for more than the corresponding raw-log value, making the Sawmill useful when you already have an established forestry operation.
