# LumberCo

**LumberCo** is a shop in **Farming And Friends** where players can purchase tree seeds and tree seed pallets.


> You will need to place down **Forest Soil for trees**
![Forest Soil](/images/ForestSoil.png)

## Tree Box Prices

LumberCo sells individual crop boxes containing seeds for different crops.

| Tree               |    Price |
| ------------------ | -------: |
| 🌲 Pine Seeds     |     $600 |
| 🍫 Cocoa Seeds      |     $70,000 |
| 🌲 Cypress Seeds      |   $150,000 |
| 🌳 Birch Seeds      |   $210,000 |


> LumberCo store in the image below
![FarmCo Crop Boxes](/images/Lumberco.png)

## Pallet Prices

LumberCo also sells tree pallets containing multiple tree boxes.

| Tree         | Pallet Price |
| ------------ | -----------: |
| 🌲 Pine Seeds     |     $15,390 |
| 🍫 Cocoa Seeds      |     $1,795,500 |
| 🌲 Cypress Seeds      |   $3,847,500 |
| 🌳 Birch Seeds      |   $5,386,500 |


## Pallet Information

* Each pallet contains **27 crop boxes**.
* Pallets are sold at approximately a **5% discount** compared to purchasing 27 individual tree boxes.
* A **forklift** is required to move the pallets.
> Pallet area within the image below
![FarmCo Crop Pallets](/images/Farmcopallet.png)

> **Note:** Prices shown on this page are based on the information currently documented and may change with future game updates.
