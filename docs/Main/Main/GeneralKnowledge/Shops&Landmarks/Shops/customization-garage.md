# 🔧Customization Garage

The Customization Garage is on the left side of the Tractor Co building. There you will find an NPC with some text that says "Customize Vehicles". 
  
  ![Customization Garage](/images/CustomizeGarage.png)


## Customization Filters
- Tractor
- Harvester
- Truck 
- Tree
- Plow
- Cultivator
- Planter
- Trailer
- Misc
- Premium

## Vehicle Menus
>📝Note: Some options below may be disabled depending on the equipment type. 
<br>
>📝Note: All items can be previewed before purchase. The ❌ icon near the price can be used to remove the item. 
<br>
>📝 Note: The default color options are black, gold, white, gray, dark red, light blue. If you have the robux color expansion, that can be used here.

| Menu Name| Description | Cost |
|---|---|---:|
|🎨Paint| Changes the main color.| 60,000|
|🖌️Wraps| Select a wrap type, select the scale size, and secondary color.| 60,000|
|📢Horns| Select a horn.| 60,000|
|🛞Wheels| Select just rims or rims and tires.| 75,000 (per rim and tire) |
|💨Tiresmoke| Adds colored smoke behind wheels. | 60,000 |
|💡Underglow | Adds colored glow under wheels. | 60,000|
|💨Exhaust | Adds exhaust affect| 60,000|
