# Bees

Bees are a livestock animal that produce **Honey Frames**. Honey Frames are processed into Honey Barrels using the **Honey Factory**.

Honey can either be sold directly or used with Oats in the **Honey Oatmeal Factory**.

## How to Obtain

Bees are purchased from the **AnimalCo Store** in **Bee Boxes**.

Each Bee Box contains **1 Bee**.

To obtain a bee:

1. Visit the AnimalCo Store.
2. Purchase a Bee Box.
3. Take the Bee Box back to your farm.
4. Place the Bee Box into an available Hive.
5. The bee will begin producing Honey Frames.

## Purchase Price

| Information | Details |
| ----------------------- | ------------------------ |
| Bee Box | 15,000 Coins |
| Bees per Box | 1 Bee |

Each Bee Box costs **15,000 Coins** and contains one Bee.

## Housing Requirements

Bees must be placed inside a **Hive**.

| Requirement | Details |
| ----------------------- | ------------------------ |
| Housing | Hive |
| Maximum Bees | 6 Bees per Hive |
| Food | Not Required |
| Cleaning | Required |

A Hive can hold up to **6 Bees** by default.

Hive capacity can be increased through certain upgrades and tasks.

## Food Requirements

Bees **do not require food**.

Unlike chickens, cows and sheep, bees do not need an Animal Food feeder.

Instead, Bees remain inside their Hive and produce Honey Frames automatically.

> **Note:** Hives still need to be cleaned regularly.

## Products Produced

Bees produce **Honey Frames**.

Honey Frames are processed using the **Honey Factory** to produce Honey Barrels.

| Product | Details |
| ----------------------- | ------------------------ |
| Honey Frame | Produced by Bees |
| Honey Barrel | Produced from Honey Frames |
| Honey Oatmeal | Produced using Honey and Oats |

Honey can be used in two main ways:

- Sold for Coins
- Combined with Oats in the Honey Oatmeal Factory

## Production Time

Bees take approximately **15 minutes** to produce Honey.

Each Bee produces **4 Honey Frames** during its production cycle.

| Information | Details |
| ----------------------- | ------------------------ |
| Production Time | 15 minutes |
| Honey Frames per Bee | 4 |
| Bees per Hive | Up to 6 |

A full Hive containing 6 Bees can therefore produce up to **24 Honey Frames** per production cycle.

## Selling Information

Honey is processed through the **Honey Factory** before being sold.

The Honey Factory converts Honey Frames into **Honey Barrels**.

Honey Barrels can then be:

- Sold for Coins
- Used to produce Honey Oatmeal

> **Note:** The current selling value of Honey can change and should be checked in-game before calculating expected profits.
