# Farming Licenses

Farming licenses cover activities, equipment, and machinery related to **farming** in Farming And Friends.

Each license uses the standard license progression system. Complete the available tasks to earn License XP and work towards unlocking the license.

## Progression

Farming licenses follow the standard license task system:

* **4 tasks** are available every **2 hours**.
* Completing tasks awards **License XP**.
* Continue completing tasks until you reach the required XP.
* Once the required XP has been reached, the license can be unlocked.

Individual farming license pages can include:
