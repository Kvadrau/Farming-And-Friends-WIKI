# Licenses

Licenses are a progression system in **Farming And Friends** that allow players to gain access to different vehicles, equipment, animals, and activities.

There are three license categories:

* 🐄 **Animals**
* 🚜 **Farming**
* 🚚 **Logistics**

Each license follows the same general progression system, with players completing tasks to earn XP towards their chosen license.

## How Licenses Work

Each license requires a certain amount of **License XP** before it can be unlocked.

Players earn License XP by completing tasks associated with the license.

### Task System

* **4 tasks** are available per cycle.
* Tasks refresh every **2 hours**.
* Completing tasks awards **License XP**.
* Continue completing tasks until the required XP has been reached.
* Once enough XP has been earned, the license can be unlocked.

## Frequently Asked Questions

### How often do tasks refresh?

License tasks refresh every **2 hours**.

### How many tasks are available?

There are **4 tasks available during each cycle**.

### Can I work on different licenses?

License progression depends on the license selected and the tasks available for it.

### How much XP do I need?

Each license has its own XP requirement. Check the relevant license page for the exact amount.
